# راست‌به‌چپ کردن چت هرمس

افزونه‌ای مستقل و قابل خاموش‌کردن برای **Hermes Desktop**؛ مخصوص خوانایی فارسی، عربی و متن ترکیبی با مسیر، کد و منشن بات‌ها. فایل‌های اصلی هرمس و متن پیام‌ها دست نمی‌خورن.

[English](README.md) · [دستور نصب برای ایجنت](AGENTS.md)

## این متن رو به ایجنتت بده

> افزونه Hermes RTL Chat رو از این مخزن برای دسکتاپ هرمس نصب کن. اول AGENTS.md، فایل plugin.js و install.py رو بخون. پوشه اصلی محلی هرمس رو پیدا کن و با اسکریپت نصب، افزونه رو همون‌جا نصب کن، نه داخل تک‌تک پروفایل‌های بات‌ها. فایل‌های اصلی هرمس، تنظیمات، رمزها و پیام‌ها رو تغییر نده؛ برنامه در حال اجرا رو نبند. فایل موجود متفاوت رو بدون اجازه جایگزین نکن. نمایش فارسی/انگلیسی و پیام گروه بات‌ها رو بررسی کن و روش خاموش‌کردن و محدودیت تست رو بگو.

## نصب

مخزن رو دانلود و استخراج یا clone کن:

```sh
git clone https://github.com/nightclaw77/hermes-rtl-chat.git
cd hermes-rtl-chat
```

بعد از بررسی فایل‌ها، داخل پوشه مخزن اجرا کن:

لینوکس و مک:

```sh
python3 install.py
```

ویندوز:

```powershell
py -3 install.py
```

مسیر پیش‌فرض «HERMES_HOME» است اگر تعیین شده باشه؛ در غیر این صورت «~/.hermes». برای مسیر سفارشی:

```sh
python3 install.py --home /path/to/hermes-home
```

افزونه داخل «desktop-plugins/hermes-rtl-chat/plugin.js» در پوشه اصلی برنامه نصب میشه. نیازی به npm، بیلد، API key یا نصب روی هر بات نیست. روی دستگاهی نصب کن که پنجره دسکتاپ هرمس رو اجرا می‌کنه.

معمولاً زنده اعمال میشه؛ اگر نشد از پالت فرمان «Reload desktop plugins» رو اجرا کن. اگر قبلاً خاموشش کردی، در تنظیمات افزونه‌ها «RTL Chat — Persian & mixed text» رو روشن کن.

## ایمنی و برگشت

- فقط جهت و ظاهر متن چت رو عوض می‌کنه؛ کل رابط، ترمینال و تنظیمات بات‌ها تغییر نمی‌کنن.
- متن ذخیره‌شده و متن انتخاب‌شده برای کپی تغییر نمی‌کنن.
- در زمان اجرای افزونه هیچ درخواست شبکه، ذخیره‌سازی، خواندن رمز یا ارسال اطلاعاتی وجود نداره.
- خاموش‌کردن از بخش Plugins، استایل‌ها و علامت‌های افزونه رو پاک و مشاهده‌گر رو متوقف می‌کنه.
- اسکریپت نصب فایل متفاوت موجود رو جایگزین نمی‌کنه، مگر با «--replace»؛ در اون حالت اول بکاپ دائمی می‌گیره.
- برای حذف، افزونه رو خاموش کن و فقط پوشه «hermes-rtl-chat» رو حذف کن.

## بعد از آپدیت هرمس چه میشه؟

افزونه بیرون از سورس و فایل بسته‌بندی‌شده هرمسه، بنابراین آپدیت معمولی نباید پاکش کنه. بااین‌حال تغییر ساختار پیام‌ها یا API افزونه در نسخه‌های آینده ممکنه نیاز به به‌روزرسانی افزونه داشته باشه. حذف پوشه اصلی هرمس هم افزونه‌ها رو حذف می‌کنه. هیچ سرویس مخفی برای نصب دوباره یا روشن‌کردن اجباری وجود نداره.

این نسخه روی لینوکس، Chromium واقعی و دسکتاپ نصب‌شده بررسی شده و نمایش گروه بات‌ها به تأیید کاربر رسیده. تست ویندوز/مک و اجرای یک آپدیت واقعی هرمس انجام نشده. اطلاعات تست و محدودیت‌های تشخیص جهت رو در README انگلیسی ببین.

افزونه مستقل است، محصول رسمی Nous Research نیست. مجوز MIT دارد. مسئله خوانایی مشابه پروژه rtl-chat-zcode است؛ پیاده‌سازی مخصوص هرمس و مستقل نوشته شده.
